# Audio Processing

Audio processing happens in the **time domain**.

The sound of an oscillator, or a sample playing back - a signal passing those through a reverb, or flanger or a distortion transfer function will alter the input sound over time, therefore it's all happening in the time domain.

Time passes; the sound changes (or not!).
